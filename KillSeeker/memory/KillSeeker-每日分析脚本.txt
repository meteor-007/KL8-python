----------------------------------------------------------------------------------------
STEP 2: 独立杀号复盘与闭环预测 (Full Prediction Loop)
----------------------------------------------------------------------------------------
目标：复盘上一期的杀号战果，并利用4大引擎（相似、密集、形态、曲线）生成下一期的纯净杀号序列。
指令：
    python main.py --full

预期输出：
    1. 上期复盘：输出高置信/中置信/全部杀号的真实验证命中率。
    2. 新期预测：通过四大引擎得分进行排序，得分极低者入选杀号库。
    3. 生成当期结果：高置信杀号 (10个)，中置信杀号 (10个)，观察区杀号 (5个)，保留号 (8个·精选)。

    当前底层架构表现:
      全部杀号成功率已稳固在 75%+，具备极强的实战缩水价值。

审查与行动：
    - 读取高置信杀号区，直接将其从大盘过滤清单中划去。
    - 中置信和观察区可作为选号时的最后过滤网。

----------------------------------------------------------------------------------------
STEP 2.5: 算法优化提纯（杀号反哺验证 + 前序系统信号交叉校验）
----------------------------------------------------------------------------------------
目标：将本系统杀号结果与前序做多系统的推荐进行交叉验证，实现"杀号反哺提纯"。
⚠️ 本系统是每日执行顺序的第6个，可读取前序做多系统(data+统计次数+LSTM+重点点位+定金选2)的结果。
后续系统(快乐8分析规律/V18)尚未执行，不可读取。

【提纯逻辑】
1. 杀号反哺验证（核心！）：
   - 读取前序做多系统的推荐号码：
     · data系统的HE5/Trinity Top5/Top12/纯净池定胆
     · 统计次数系统的Top10/金胆
     · 双层LSTM的Top10/金银铜胆
     · 重点点位分析的精选十码/核心五码
     · 定金选2的金胆及Top组合搭档号
   - 将本系统高置信杀号与前序做多推荐取交集 → 标记"危险信号号码"（做多推荐但被杀号否决）
   - 将本系统保留号与前序做多推荐取交集 → 标记"共振确认号码"（做多+不被杀=高置信）
   - 输出交叉验证矩阵：
     ┌─────────────────────┬───────────────────────────────────┐
     │ 分类                 │ 含义                              │
     ├─────────────────────┼───────────────────────────────────┤
     │ 🔴 危险信号号码       │ 前序做多推荐 ∩ 高置信杀号         │
     │                     │ → 强烈建议从做多池中剔除          │
     │ 🟡 需复核号码         │ 前序做多推荐 ∩ 中置信杀号         │
     │                     │ → 谨慎参考，降权处理              │
     │ 🟢 共振确认号码       │ 前序做多推荐 ∩ 保留号             │
     │                     │ → 多系统一致认可，优先选入        │
     │ ⚪ 独立杀号           │ 高置信杀号 - 前序做多推荐         │
     │                     │ → 做多系统未推荐，杀号风险较低    │
     └─────────────────────┴───────────────────────────────────┘

2. 杀号覆盖率统计：
   - 统计高置信杀号对前序系统Top10的"击杀率"（杀掉几个/总共几个）
   - 若击杀率>50%：说明多系统信号严重分歧，本期随机基线，建议观望
   - 若击杀率<20%：说明杀号与做多系统方向一致，本期信号可靠度较高

3. 杀号稳定性回溯：
   - 从logs/kill_logs.jsonl提取最近5期杀号结果
   - 统计连续命中（正确杀号）和连续漏杀的号码
   - 连续3期以上正确杀号的号码 → 本期杀号置信度+1级
   - 连续2期以上漏杀的号码 → 本期从杀号池降级为观察区

4. 输出提纯报告：
   - 危险信号号码列表（附具体来源前序系统）
   - 共振确认号码列表（附具体来源前序系统）
   - 杀号击杀率与混沌度评估
   - 杀号稳定性回溯结论

审查与行动：
   - 🔴危险信号号码：必须从所有做多推荐中剔除
   - 🟡需复核号码：降低权重至0.5x
   - 🟢共振确认号码：可提高选入优先级

【提纯复盘 — 回验上期杀号反哺结果】
  - 读取上期本系统的杀号反哺输出（危险信号号码/共振确认号码/击杀率/稳定性回溯等）
  - 对照上期实际开奖，验证：
    · 🔴危险信号号码（做多推荐∩高置信杀号）实际未中 → 杀号反哺是否准确剔除？
    · 🟢共振确认号码（做多推荐∩保留号）实际命中 → 双重确认是否可靠？
    · 🟡需复核号码（做多推荐∩中置信杀号）实际命中 → 降权0.5x是否合理？
  - 统计近5期杀号反哺区分力：
    · 危险信号号码未中率 vs 共振确认号码命中率 → 反哺区分力指数
    · 区分力指数>1.5x → 杀号反哺有效 ✅
    · 区分力指数1.0-1.5x → 杀号反哺微弱 ⚠️
    · 区分力指数<1.0x → 杀号反哺无效 ❌
  - 击杀率复盘：
    · 上期击杀率是否>50%？若是 → 多系统信号严重分歧期，杀号是否该更激进？
    · 上期击杀率是否<20%？若是 → 信号一致期，杀号是否该更保守？
  - 杀号稳定性回溯复盘：
    · 连续3期正确杀号的号码本期杀号是否依然准确？
    · 连续漏杀降级的号码是否确实不该杀？

【优化闭环 — 轻量建议（不做自动改权重）】
  - 反哺复盘结论仅输出人工建议，不自动改引擎权重（防过拟合）：
    · 若反哺有效 → 维持当前杀号反哺逻辑
    · 若反哺微弱/无效 → 危险信号降级为仅供参考，不强制剔除做多推荐
  - 击杀率阈值保持 50%/20%，本期仅展示是否分歧/一致
  - 反哺结果持久化写入 logs/kill_logs.jsonl 的 cross_feed 字段
