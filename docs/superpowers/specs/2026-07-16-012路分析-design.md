# 012路分析子系统 — 设计规格

**日期：** 2026-07-16  
**状态：** 待用户审阅后进入实现计划  
**范围：** 快乐8（1–80 选 20）012 路分路、深度关联挖掘、下期分路比预测、分层推荐/杀号

---

## 1. 产品一句话

独立 CLI 统计规则引擎（增强 logistic / 随机森林），将快乐 8 的 80 个号码按余数分 0/1/2 路，基于历史开奖深度挖掘分路分布关联与规律，输出下期分路比预测及按分路倾斜的分层推荐/杀号。

## 2. 已确认需求

| 项 | 选择 |
|----|------|
| 产出 | A+B+C：深度分析 + 下期分路预测 + 号码倾斜（推荐/杀号） |
| 形态 | CLI 独立工具（对齐 KillSeeker） |
| 号码输出 | 分层：高/中/低置信推荐 + 高/中置信杀号 |
| 引擎 | 方案 1 统计规则为主 + logistic/RF 增强 |
| 数据 | `data/kl8_history_final.txt` |

## 3. 分路规则（与仓库一致）

| 路 | 定义 | 号码数 | 号码 |
|----|------|--------|------|
| 0路 | `n % 3 == 0` | 26 | 03,06,09,…,78 |
| 1路 | `n % 3 == 1` | 27 | 01,04,07,…,79 |
| 2路 | `n % 3 == 2` | 27 | 02,05,08,…,80 |

每期开出 20 个号 → 分路向量 `(r0, r1, r2)`，`r0+r1+r2=20`。  
理论期望约 **7:7:6**（因 0 路少 1 个号，略偏向 1/2 路）。

## 5. 数据流

```
kl8_history_final.txt
        │
        ▼
  data_loader ──► draws[]: {date, period, numbers[20], road=(r0,r1,r2)}
        │
        ├─► distribution / transition / association ──► 分析报告块
        │
        ├─► predictor (+ ml_predictor) ──► 下期 Top 分路比 + 置信度
        │
        └─► number_scorer ──► 高/中/低推荐 + 高/中杀号
                │
                ▼
        main.py 打印 + 写入 outputs/
```

历史行格式：

```
date:YYYY-MM-DD,period:YYYYNNN,numbers:NN-NN-...-NN
```

解析失败行跳过并计数告警；启动时打印最新 `period`。若同日 `daily_points.txt` 存在且期号更新，打印滞后警告（不强制合并，避免双源冲突）。

## 6. 分析模块（`--analyze` / 完整流程）

1. **分布：** 全量与近窗（默认 100/300）均值、方差、相对期望偏离  
2. **Top 形态：** 离散比频次 Top10  
3. **转移：** 本期比 → 下期比；状态用精确 `(r0,r1,r2)`，稀有态加 Laplace 平滑；报告另附「主导路」（max 路）粗转移表便于阅读  
4. **Streak：** 某路连续偏高/偏低期数分布与当前 streak  
5. **关联：** 分路比与和值区间、奇偶比的条件频率（报告用，不主导预测）  
6. **热冷路：** 近窗各路出现量 vs 期望，提示回归/延续

## 7. 分路比预测融合

| 信号 | 默认权重 | 说明 |
|------|----------|------|
| 马尔可夫 / 转移 | 0.35 | 基于近期状态转移 |
| 频率回归 | 0.25 | 向经验分布/期望拉回 |
| Logistic / RF | 0.40 | 近窗序列特征 → 下一比类别或各路计数回归 |

输出：最可能比、Top3 候选比、综合置信度。  
`--no-ml` 时将 ML 权重按比例摊给前两项。

**ML 要点：**
- 特征：近 k 期 `(r0,r1,r2)`、偏离、streak、和值粗分箱（可选）  
- 模型：分路比可用多输出回归或分类（离散 Top 形态）；号码倾斜可用逐号概率或按路内排序特征  
- 训练：滚动窗口，默认用近 500 期拟合、更早作可选验证；模型可缓存至 `outputs/models/`  
- 依赖：`scikit-learn`；训练失败则自动降级为纯统计并告警

## 8. 分层号码默认量

| 层 | 推荐 | 杀号 |
|----|------|------|
| 高置信 | 8 | 8 |
| 中置信 | 8 | 7 |
| 低置信 | 6 | 无（避免低置信误杀） |

号码分 = 预测分路权重倾斜 × 遗漏/冷热 ×（可选）RF 号码分；同分按路内均衡打散。  
数量与权重均在 `model_config.py`，CLI 可覆盖。

## 9. CLI

| 命令 | 行为 |
|------|------|
| `python main.py` | 分析 + 预测 + 分层号码 + 落盘 |
| `--analyze` | 仅深度分析 |
| `--predict` | 仅分路比 + 分层号码 |
| `--review` | 复盘上期预测 vs 实际开奖 |
| `--backtest N` | 近 N 期滚动回测指标 |
| `--no-ml` | 关闭 ML 分支 |
| `--window N` | 分析近窗覆盖 |

## 10. 验收（P0）

1. 上述命令在本地历史数据下可跑通  
2. 分路映射：80 号全覆盖、无重复、与 `% 3` 一致  
3. `outputs/` 写出 txt + json  
4. 回测输出：分路比精确命中率、Top3 命中率、杀号「未开出」率、推荐层覆盖开出号比例  
5. 完整运行（含首次 RF 训练）目标 < 60s；有缓存时更快

## 11. 边界（明确不做）

- 不定最终 20 码投注单（非聚合器）  
- 无 GUI / Web / 实时抓取  
- 不宣称可稳定战胜随机；报告须带期望与回测区间说明

## 12. 风险与对策

| 风险 | 对策 |
|------|------|
| 近随机、规律弱 | 统计可解释为主；ML 可关；回测必出 |
| RF 过拟合 | 少特征、滚动窗、`--no-ml` |
| 历史滞后 | 打印最新期；可选与 daily_points 期号对比警告 |

## 13. 错误处理

- 历史文件缺失：清晰报错并退出非零  
- 单行解析失败：跳过 + 汇总告警  
- ML 训练/预测异常：降级纯统计，不中断主流程  
- 回测 N 大于可用期数：截断为可用最大值并提示

## 14. 测试要点

- `road_mapper`：固定断言 0/1/2 路集合大小 26/27/27  
- `data_loader`：样例行解析出正确 `road` 和  
- `predictor`：`--no-ml` 与默认路径均可产出合法比（和为 20）  
- `number_scorer`：各层数量正确、推荐与杀号无交集  
- `main --backtest 10`：退出码 0 且指标键齐全
