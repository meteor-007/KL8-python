# 试验登记（研究自由度）

对应复盘报告 5.1.11：记录在同一份档案上试过的所有试验，用于 Bonferroni /
期望最大 z / DSR / PBO 的自由度校正。

## 为什么需要

在同一份 335 期档案上试过 11 个方法、7 维权重、门控、护栏、阈值、十余项修复。
即使每个检验单独 p<0.05，试得越多，“最好那个”越可能是噪声。
登记表把**已经花掉的自由度**显式记录出来：

- 家族大小 N → Bonferroni 阈值 α/N；
- N 次零试验下最大 z 的期望 → 与观测最好的 z 对比；
- 预注册前的试验数 → 前瞻性分析的清洁度检查。

## 文件与命令

| 文件 | 作用 |
|---|---|
| `prereg/trials.jsonl` | 只追加的试验登记（一行一个试验） |
| `tools/trials.py` | 登记/汇总逻辑（审计工具，不在冻结代码哈希内） |
| `scripts/trials.py` | CLI |

```bash
# 登记一个新试验
python scripts/trials.py add --id T-001 --family methods --category method \
    --description "某方法的外样本检验" --z 1.2 --q 0.4 --lift 1.03 --T 60

# 查看
python scripts/trials.py list --family methods-60
python scripts/trials.py summary
python scripts/trials.py registration      # 对照预注册：登记前/后试验数

# 一次性写入已知历史试验（11 方法 + 4 规律 + 15 修复 + 5 设计 + 1 预注册）
python scripts/trials.py seed --report output/2026-11-10/daily_report.md
```

## 当前汇总（2026-11-10）

| 家族 | N | Bonferroni α | E[max z] | 最好 z | 最好 q | 判定 |
|---|---|---|---|---|---|---|
| methods-60 | 11 | 0.00455 | 1.587 | 1.642 | 0.5017 | 略高于期望，需独立复现 |
| fusion-laws | 4 | 0.01250 | 1.031 | — | — | 未验证 |
| evaluation-fixes | 16 | 0.00313 | 1.769 | — | — | 工程修复，不作为优势证据 |
| design-choices | 5 | 0.01000 | 1.164 | — | — | 人工设计选择 |
| prereg | 2 | 0.02500 | 0.564 | — | — | 计划中 |
| **总体** | **38** | **0.00132** | **2.142** | **1.642** | — | **与零分布最大 z 一致（噪声）** |

结论：在 38 次试验的自由度下，观测到的最好 z（1.642）低于 38 次零试验最大 z 的
期望（2.142）；按 Bonferroni，阈值是 α=0.00132，对应 z≈3.01。没有任何结果通过。

## 边界

- 登记表本身是审计元数据，**不参与预测路径**；它不在 `kl8/*.py` 的冻结哈希内，
  因此新增登记不会让预注册失效。
- “试验”是人工登记的；自动扫描只能覆盖有明确结果表的项。未登记的隐式试验
  （临时改阈值、换窗口、看不同分组）仍会低估自由度——所以默认应把 N 视为下限。
- DSR/PBO 的完整计算需要每个试验的收益序列；当前实现提供 Bonferroni 与
  期望最大 z 两个保守近似，足以判断“最好结果是否只是噪声”。
