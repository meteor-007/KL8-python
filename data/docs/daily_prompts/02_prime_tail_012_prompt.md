## 1. 思考模式（必须按此顺序想）

### 1.1 时间锚点
- `audited_period` / `based_on_period_for_audit`：刚开期 = 复盘对象  
- `target_period`：刚开期 + 1 = 预测目标  
- 推演只用截止「刚开期」的数据；对账用「再上一期推演稿」对照刚开实开

### 1.2 尾号三维（0～9）
对刚开 20 码按尾拆：
- 属性：质专属尾 `1/3/7/9`｜合专属尾 `0/4/6/8`｜混尾 `2/5`（含 02/05）
- 出号个数 + 具体号码 + 研判标签：  
  - 出 0 → **全灭，防反弹**（下期主攻回补）  
  - 出 ≥4 → **过热，防回调**（下期减仓）  
  - 出 1 → 偏冷待命  
  - 出 2～3 → 温热活跃  
- 汇总：质主战尾个数 / 合主战尾个数 / 混尾个数  
- 香农熵：读 `shannon_entropy`、`max_entropy`、`entropy_ratio_pct`、`entropy_state`  
  - 高熵发散 → 分散布局，忌扎堆同尾  
  - 低熵偏科 → 写清哪几尾垄断，下期防回调/补弱尾

### 1.3 012路结构
- 路定义：`n % 3` → 0/1/2 路  
- 给出：各路个数、号码清单、比值 `r0:r1:r2`、`regime_alert`、`tactical_bias`  
- 规则：  
  - 均衡（如 6～8 一带）→ **三路轮动，勿押单路**  
  - 某路极端偏少/偏多 → 可略抬权重，但**禁止**写成「必爆发/胜率88%」；若有 `extreme_backtest`，必须用回测均值口径  

### 1.4 质合结构
- 1～80：严格 22 质数；合数池；1 单独可标「非质非合」若出现  
- 统计刚开质/合个数与名单  
- 质少合多 → 下期 VIP 质数池可提权；合多且合尾过热 → 合数里挑温热、不追过热尾  

### 1.5 昨推复盘对账（必须有）
读 `last_period_audit`（或等价字段）：
- 质数最优3码：推荐 / 实中 / 命中数  
- 孪生对：推荐 / 实中 / 是否双飞  
- 可选：尾5爆发、012 好码 15 码命中等（有则写，无则跳过）  
- 结论用大白话：方向对不对、对码准不准、弹簧是否继续憋

### 1.6 下期形态研判（同类口诀）
统一用四字格：
- **过热防回调** / **全灭防反弹** / **偏冷轻抬** / **温热陪跑** / **均衡勿单押**  
做成「维度 | 形态判断 | 操作含义」表，覆盖：尾号、012路、质合、熵

### 1.7 精选落地顺序
1. **尾号作战表**（优先级 ★★★～▲）  
2. **质数 VIP（方案三 · 22→最优3码）**：表含 号/尾/遗漏/动能分/标签/与尾策略对齐  
3. **孪生质数（方案四）**：首选 1 对 + 次席；写遗漏与弹簧倍数  
4. **012路好码**：三路各列好码与头牌；至少 2 组跨路选2  
5. **多维共振**（若有 `multi_resonance_consensus`）：黄金核心5 / 共振12 / 防守剔除参考（注明非硬杀） / 最佳共振对  

### 1.8 诚实口径
- 012 近窗 lift 若接近 1.0，只能写「弱优势/近随机」，禁止「碾压」  
- 杀号/剔除只作防守参考，不硬踢主核  
- 与 16期中热交叉：只点 1～3 个桥接号，不重写中热全文
