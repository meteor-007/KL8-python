## 1. 方法2 六席固化规程（引擎 `method2_bucket_mix_v1`）

| 席 | 算法取法 | 并列打破 |
|----|----------|----------|
| ① | 频5 **精选头** `pick5[0]` | — |
| ② | 频5 **剩余 ∩ 出窗边** 优先，否则 `rest5[0]` | 列表序先 |
| ③ | 频4精选 `omit≥1` 中 max midhot | 取 pick4 **列表最靠后** |
| ④ | 频4剩余 ∩ 出窗同源4 | max(recent_8, -omit)，再取小号 |
| ⑤ | 频4剩余 `omit=0` 且**非同源**且未入选 | max midhot，并列取小号 |
| ⑥ | 频3剩余 `omit∈[2,6]` | max midhot，并列取小号 |

## 3. 对账计分规则（必须写清）

### 3.1 方法1
- tip3：每中 1 码记 1；满分 3  
- 回补金/银/铜：各中记 1；满分 3（与 tip3 分开记，不合并吹捧）  
- 选2：整对双飞记「双飞」；只中 1 记「单飞」；0 记「空」  
- 点位：tip3 中有几点位命中 / tip3 内点位席位数  

### 3.2 方法2
- 六码：每中 1 记 1；满分 6；并标注命中率 = 中/6  
- 按席位①～⑥分别勾中否（用于看哪条取法有效）  
- 三组选2：同方法1（双飞/单飞/空）  

### 3.3 结构旁证（不计「主票胜负」，单独记账）
- 出窗同源队：命中个数 / 掉到3名单 / 留在4名单  
- 动量精选7个4：命中个数与名单  
- 方法1∩同源、方法2∩同源 各自命运  

### 3.4 诚实口径
- 单期命中波动大，禁止「稳赚/碾压」  
- 方法2 若长期弱于随机六码，降为观察，不升主轨  
- 方法1 始终主票，除非用户明文改宪
