### 🔍 为什么会弹出“服务启动后停止”？（技术根因剖析）
Windows 系统服务（Session 0 底层运行）与常规命令行程序不同：
1. **线程信号冲突**：Windows SCM（服务管理器）是在独立的系统工作线程中拉起 Python 服务的，而底层 Web 框架（Uvicorn）默认会试图向“系统主线程”注册 POSIX 信号（`signal.signal`）和查询控制台颜色（`sys.stdout.isatty`）；
