### 🎯 业务功能模块与前端菜单对照

1. **`backend/api/`（Web API 与数据服务）**：承载 FastAPI 后端接口与 `QuantDataService` 数据提炼层，与前端大屏无缝通讯。
2. **`backend/core/`（核心操盘研判 / 算法模型实验室）**：集纳高斯流能场（EF 蹭热度）、遗漏回补（RW 抓冷门）、傅里叶谐波（FO 找周期）、纯净池（守号）、定金选2（找连体婴最佳搭档）等核心算法。
3. **`backend/data_acquisition/`（数据采集与资产同步）**：自动爬取官网历史开奖、生成热码 Excel 报表、增量同步历史数据。
4. **`backend/pipeline/`（自动化推演流水线）**：每日开奖后自动化端到端推演，输出标准格式研判报告。
5. **`backend/audit/`（复盘回测与风控审计）**：胜率警告机制、三维权重平衡性审计与 KL 散度大环境变盘监控。
6. **`backend/learning/`（自主学习与模拟实盘）**：自主根据历史开奖反馈微调打分参数，并进行模拟盘胜率统计。
7. **`backend/recognition/`（环境态势识别）**：快速识别盘面冷热与区间偏向。
8. **`backend/format/`（表格样式引擎）**：Excel 自动上色与中奖边框渲染。
9. **`backend/config/`（配置中心）**：集中管理模型 YAML 与 JSON 参数。
10. **`backend/utils/`（底层工具中枢）**：统一路径解析器（`paths.py`）、多进程并发文件排他锁、数据一致性校验与自愈。
