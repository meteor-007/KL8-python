# 🎨 K8-Quant Web 极致暗黑赛博 UI/UX 视觉与交互设计规范 (UI Spec v1.0)

## 1. 界面设计定位与风格定义 (Visual Identity)

本系统定位为 **专业级高频量化操盘决策终端**。
视觉设计语言融合 **暗黑赛博朋克 (Cyberpunk Dark)** 与 **专业金融终端 (Bloomberg/TradingView Dark UI)** 风格：
- **基调**：深灰蓝夜空底（`#0B0F19`），沉浸感极强，适合长时间看盘与数据分析。
- **高对比度荧光强调**：
  - **核心金胆 (Gold Glow)**：`#F59E0B` / `#FBBF24` (带金色光晕，突出黄金推荐)
  - **赛博冷光青 (Cyan Neon)**：`#06B6D4` / `#22D3EE` (系统主特征与科技信标)
  - **能量热力红 (Crimson Hot)**：`#EF4444` / `#F87171` (高能热区与爆发号段)
  - **遗漏回补紫 (Electric Purple)**：`#8B5CF6` / `#A78BFA` (冷号憋到极限回补)
  - **信标绿 (Emerald Green)**：`#10B981` (正常状态与胜率达标)

## 3. 核心交互组件规范 (Component Specifications)

### 3.1 核心金胆卡片 (Top 5 Gold Core Cards)
- 带有金色微发光边框（`box-shadow: 0 0 15px rgba(245, 158, 11, 0.25)`）。
- 球号采用大字体粗体，数字圆徽章展示，右侧展示综合得分（如 `0.942`）与核心驱动标签（如 `蹭热度` / `抓冷门` / `找周期`）。

### 3.2 80 码全景态势矩阵 (80-Cell Heatmap Matrix)
- 8 行 10 列排布，共 80 个号码单元格。
- 动态状态颜色：
  - **金胆 (Top 5)**：金黄底色高亮脉冲
  - **候选 (Top 12)**：青蓝边框发光
  - **极热点位 (Hot)**：深红渐变
  - **冷号回补 (Cold Rebound)**：紫蓝渐变
  - **普通点位 (Neutral)**：半透明灰蓝
- **交互动作**：鼠标悬停（Hover）显示 Tooltip 弹窗，点击（Click）弹出号码近 30 期出号历史与搭档关联度。

### 3.3 三维融合雷达图 (Trinity Radar Chart)
- 三个主维度：`EF 蹭热度`、`RW 抓冷门`、`FO 找周期`，支持多期对比。

### 3.4 自动化流水线黑客控制台 (Terminal Log Streamer)
- 黑色背景与绿色/青色字体，支持流式日志逐行打字机效果。
- 具有实时任务状态指示器（待命 / 正在计算 / 完成 / 失败）。

## 4. 响应式与跨端适配 (Responsive Rules)
- **宽屏大屏 (≥1440px)**：三栏并排全功能全景看板。
- **笔记本屏幕 (1024px ~ 1439px)**：两栏弹性自适应，图表自动重排。
- **平板与移动端 (<1024px)**：单栏纵向流式瀑布流，导航栏转为移动端抽屉式菜单。
