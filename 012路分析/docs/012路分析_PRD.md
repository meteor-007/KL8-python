# 012路分析 PRD

## AI 速读卡

- 产品一句话：快乐8 012路 CLI —— 分路映射、深度统计关联、马尔可夫+回归+RF 融合预测分路比、分层推荐/杀号。
- 核心循环：加载历史 → 分布/转移/streak 分析 → 融合预测 → 分层号码 → 落盘/复盘/回测。
- 目标平台：Windows PowerShell / Python 3.10+ CLI。
- 硬约束：分路=`n%3`；推荐与杀号无交集；ML 失败自动降级；不宣称可战胜随机。
- 推荐默认：融合权重 0.35/0.25/0.40；推荐 8+8+6；杀号 8+7。
- P0 验收：`python main.py` / `--backtest 30` 可跑通；`outputs/` 有 txt+json。

## 范围

| 在范围内 | 不在范围 |
|----------|----------|
| 深度分析、分路比预测、分层推荐/杀号 | 最终20码投注单 |
| 复盘、回测 | GUI / 实时抓取 |
| `--no-ml` 降级 | 跨彩种 |

## CLI

```
python main.py
python main.py --analyze
python main.py --predict
python main.py --review
python main.py --backtest 30
python main.py --no-ml
```
