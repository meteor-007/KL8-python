## [2026-05-26] V4.0 深度洗净与消除数学死区 (Deep Refactoring & Math Dead-End Elimination)

### 1. 历史缺陷反思 (Retrospective Analysis)
在 V3.x 版本中，系统频繁触发 **Level 3 (零信标等权降级)**，导致完全失去预测攻击性。经深度审计发现：
- **统计学谬误**：由于 80 个号码的截面数据极其有限，最大理论 Z-score 不超过 8.88。而当时使用了自由度 `df=4` 的 Student-t 极值生存函数，在肥尾效应下，要求 Z > 10 才能突破 Bonferroni 的 $p < 0.000625$ 检验。这在物理上是不可能的，构成了一个死锁防线。
- **数据饥饿**：“各向异性硬分流”强行将训练集（本来就只有百余期）劈成三份（回归、动量、平衡），导致 Logistic 回归面临小样本过拟合，模型学习到的几乎全是白噪声。
- **贝叶斯先验扭曲**：手动外挂 0.25 的先验概率进行相乘，而底层 Sklearn 使用 `class_weight='balanced'` 时本身已经调整了截距（默认含 0.5 先验），导致后验概率空间严重挤压变形。

### 2. 核心架构重组 (Architecture Restructuring)
针对以上缺陷，系统完成了向 **V4.0 全局概率校准架构** 的演进：
1. **废弃硬分流，回归全局模型**：取消了对训练集切割的 `phase` 逻辑，采用单一的高内聚 Logistic Regression 模型，将原有的相位（Hurst）与冷热偏离度转化为“连续数值特征”进行模型内部交互，保留全量训练数据。
2. **剔除共线性特征**：去除了高度冗余且容易导致过拟合的 `hit_rate_3`、`hit_rate_5`、`hit_rate_10`、`hit_rate_20`。只保留正交性强的物理核心特征：微观Hurst、冷热Z-score、遗漏均值偏离、网格集中度、时空引力场。
3. **真实概率校准 (Platt Scaling)**：引入 `CalibratedClassifierCV` (Sigmoid Cross-Validation)，强制让底层模型输出真实、无偏的发生概率，彻底废除手动贝叶斯先验相乘逻辑。
4. **对数几率显著性映射 (Logit Space Z-score)**：修复 $p$-value 计算死区。将概率有界空间 $[0, 1]$ 映射至无界的对数几率空间（Logit $=\ln(p / (1-p))$），在该空间内计算 Z-score 并采用标准正态分布 `scipy.stats.norm.sf` 进行显著性检验。

### 3. 自我学习与优化目标 (Self-Improvement Targets)
- **水位追踪**：系统现已具备在单点上突破 Bonferroni (Level 0/1) 的信度阈值。后续复盘应关注 `prediction_logs.txt` 中实际命中的号码，其事前特征是否表现为 `micro_hurst < 0.45` 伴随 `cold_hot_bias < -1.5` 的共振。
- **动态阻尼微调**：当前平滑阻尼 $\tanh(8.0 \times (AUC - 0.5))$ 的系数可能需要基于未来 30 期的样本外 OOF (Out-of-Fold) 结果进行自适应校正。
- **空间引力场升级验证**：目前的 `spatial_temporal_gravity` 计算相对静态，下一步考虑将其权重参数化，基于真实收益进行贝叶斯寻优。

### 2. 反向覆盖机制设计
- 从 `prediction_logs.txt` 读取最近5期推荐区域
- 统计每个十年区间(01-10, 11-20, ..., 71-80)零覆盖次数
- 零覆盖次数 ≥ 3 的区间，从候选池取该区间得分最高的区域强制纳入
- 强制纳入后若超过 top_k，移除得分最低的非强制区域
