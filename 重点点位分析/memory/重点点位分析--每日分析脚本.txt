重点点位分析 快乐8 每日分析脚本（v2，2026-08-24 重建）
================================================================
【这是什么】"点位"规律引擎：把 80 个号码拆成 80 个点位，每个点位带一个
        三号区(±1)，先挑出最有希望开出的点位区域，再从点位区域里精排具体号码。
        原 V6.0/V6.1 用 GBDT+微Hurst+引力场等复杂特征栈，代码被清空且演化日志
        自证长期无信号(OOF AUC≈0.50)，按"过于复杂且无增益可移除"原则重建为
        透明可审计的简化打分。
【每天怎么跑】（一条命令）
    python 每日分析.py 30
    （30 = 复盘最近30期，可改）

【重建版打分逻辑（全可解释）】
  特征：遗漏强度gap / 冷热Z freq / 邻区热度reg(±1) / 邻居引力neb(±2)，权重
        0.35/0.20/0.25/0.20 → 加权Z → sigmoid 映射到 0.50~0.65。
  结构保持原系统：一级区域 → 二级精排 Top10 / Core5 / 扩展15 → 置信等级 → 近N期复盘。
  数据：只读共享 data/kl8_history_final.txt，无泄露（每期只用该期之前的数据）。

【脚本做了什么】
  ① 无泄露回填：为最近 N 期 + 目标期各生成一套干净推荐（只用该期之前数据）。
  ② 置信评估：近20期 walk-forward Top10 平均命中 vs 随机基线 25%，做显著性检验。
  ③ 今日预测：目标期 核心五码 / 精选十码 / 扩展十五 / 空间均衡 / 点位Top10明细。
  ④ 近N期复盘：逐期对账 Top10/Core5/区域命中，算 Lift（≥1.05x 才有意义）。
  ⑤ 对照：原系统2026218记录（代码清空前）。
  ⑥ 落盘：output/重点点位预测.txt。

【口径与诚实结论】
  - 随机基线：Top10/Core5 猜 10/5 码平均中 2.5/1.25 个（25%）；区域(三号区至少一中)≈58.3%。
  - 2026-08-24 实测（重建版，近30期无泄露）：Top10 2.43/10 Lift=0.97x ❌ ≈基线；
    Core5 1.33/5 Lift=1.07x ⚠️；区域 61.0% Lift=1.05x ⚠️。总体没有抓到稳的信号，
    置信等级 = 无置信(Level 3)。不要把它当必然，按"约等于随机"对待。
